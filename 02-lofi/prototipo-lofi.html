Gestor Job — Visão de fluxo + protótipo lo-fi

Sistema multi-tenant de gestão de tarefas para agências de marketing: Kanban operacional, timesheet por fases e margem real por cliente. Este HTML é um wireframe de baixa fidelidade para alinhamento — não é a UI final.
