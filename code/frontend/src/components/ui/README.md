# components/ui

Componentes reutilizáveis atômicos (botão, input, modal).

Botões: CTA com verbo, uma linha, um ícone, um primário por view. Disabled de submit leva “Processando…”.
Data: `CampoData` — máscara DD/MM/AAAA + calendário nativo.
Lista CRUD: `AcoesLista` — **Editar** e **Excluir** visíveis na linha. Ver `educraft-devkit/standards/UX-PROTOTIPO.md`.
