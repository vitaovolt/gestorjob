## Tokens principais

| Token | Hex | Uso |
|-------|-----|-----|
| `--moss` | `#204038` | Navegação, OK, estrutura (Gestor) |
| `--orange` | `#F06820` | CTAs, timer ativo, progresso (Job) |
| `--moss-soft` | `#E6EFEC` | Fundos suaves |
| `--orange-soft` | `#FFF0E8` | Fundos de ação |
| `--ink` | `#1A2220` | Texto |
| `--bg` | `#F3F6F4` | Fundo da app |
| `--warn` | `#B86A14` | Alerta operacional |
| `--danger` | `#B42318` | Atraso |
| Fonte display | Nunito 400–800 | Evitar Inter / Roboto / Arial |
| Slogan | Organize · Descomplique | ORGANIZE (moss) · DESCOMPLIQUE (orange) |

## Ligação com hi-fi

O `prototipo-hifi.html` usa os mesmos tokens (`--moss`, `--orange`, Nunito). Não há segunda paleta.

## Regras rápidas

- Arco do logo = borda de relógio / linha do tempo do job
- Laranja só em ação e timer
- Atraso nunca vira coluna do Kanban
